# Xenolith 1.9.1

Xenolith's window and tray icon now look like XenoNet's: near-black surfaces and a mint accent in Chakra Petch and JetBrains Mono, with squared corners. The window is dark whatever the system setting says. The tray icon is three layers of stone, mint when healthy, with an amber dot when it needs attention and grey with a red dot when the service is down. Nothing else changes.

## Install

Download the archive for your machine and `SHA256SUMS` from this release. Unpack the archive anywhere and run `xenolith install` in the unpacked folder. The installer copies the programs into Xenolith's own folders, so you can delete the download afterwards. A later release's `xenolith install` upgrades in place and leaves what the shared context holds alone.

| Machine | Archive |
| --- | --- |
| Mac with Apple silicon | `xenolith-1.9.1-darwin-arm64.tar.gz` |
| Mac with an Intel processor | `xenolith-1.9.1-darwin-x64.tar.gz` |
| Linux x64 | `xenolith-1.9.1-linux-x64.tar.gz` |
| Windows x64 | `xenolith-1.9.1-win32-x64.zip` |

### macOS

```bash
cd ~/Downloads
curl -LO https://github.com/willctl/xenonet/releases/download/xenolith-v1.9.1/xenolith-1.9.1-darwin-arm64.tar.gz
curl -LO https://github.com/willctl/xenonet/releases/download/xenolith-v1.9.1/SHA256SUMS
shasum -a 256 -c SHA256SUMS --ignore-missing
tar -xzf xenolith-1.9.1-darwin-arm64.tar.gz
cd xenolith-1.9.1-darwin-arm64
./xenolith install
```

On an Intel Mac, use `darwin-x64` in the names. The programs are signed ad hoc and not notarized, so macOS refuses to run them when a browser downloaded the archive. Download with `curl` as above, or run `xattr -dr com.apple.quarantine xenolith-1.9.1-darwin-arm64` on the unpacked folder before installing. The programs go to `~/Library/Application Support/Xenolith`.

### Linux

```bash
curl -LO https://github.com/willctl/xenonet/releases/download/xenolith-v1.9.1/xenolith-1.9.1-linux-x64.tar.gz
curl -LO https://github.com/willctl/xenonet/releases/download/xenolith-v1.9.1/SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing
tar -xzf xenolith-1.9.1-linux-x64.tar.gz
cd xenolith-1.9.1-linux-x64
./xenolith install
```

It runs on glibc 2.39 or later, such as Ubuntu 24.04 or Debian 13. The tray needs GTK 3, WebKitGTK 4.1 and the Ayatana app indicator. On Debian or Ubuntu: `sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0 libayatana-appindicator3-1`. The programs go to `~/.local/share/xenolith`.

### Windows

Open a normal terminal (Win+R, `cmd`, Enter), not the terminal inside the Claude or ChatGPT desktop app. Then:

```bat
cd %USERPROFILE%\Downloads
certutil -hashfile xenolith-1.9.1-win32-x64.zip SHA256
tar -xf xenolith-1.9.1-win32-x64.zip
cd xenolith-1.9.1-win32-x64
xenolith.exe install
```

Compare the hash `certutil` prints with the zip's line in `SHA256SUMS`. Approve the administrator prompt: it registers the Xenolith service. The programs aren't signed, so Windows may say the publisher is unknown. They go to `%LOCALAPPDATA%\Xenolith`.

### After installing

Restart the Claude and ChatGPT desktop apps so they load the plugin and the server. Then sign the curator in once: tray icon > **Curator** > **Sign in to ChatGPT for the curator...**. Until then, notes wait in the inbox. `xenolith uninstall` takes Xenolith out of the apps again, and the [README](https://github.com/willctl/xenonet/blob/main/xenolith/README.md) says what it leaves in place.

## Upgrading

Run `xenolith install` from the unpacked 1.9.1 archive. It upgrades in place and leaves what the shared context holds alone. On a machine that still has agent-wiki, follow the steps in the [1.9.0 notes](1.9.0.md#moving-from-agent-wiki) first.
