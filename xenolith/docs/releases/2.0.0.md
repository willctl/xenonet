# Xenolith 2.0.0

Each space now has a signed chain that says who owns it and who may use it, and machines sync over their own encrypted connection instead of HTTP. A folder made by 1.x keeps working as it is until you run `xenolith upgrade --run`, and `xenolith upgrade --undo` takes that back.

## Changes

- **A chain per space.** Who owns a space and who may read, append to or write it is kept in a signed chain in the state folder. Each space folder gets a `xenolith-space.json` marker, signed by this Xenolith ([FORMAT.md](../../FORMAT.md)). `xenolith spaces` lists each space with its id and owner.
- **Tokens are grants.** A token is now a signed grant scoped to the spaces it names, and every decision on a space goes through one check. Tokens made by 1.x don't work in 2.0.
- **Sync between machines.** Machines sync directly over an encrypted QUIC connection on UDP 47851. They use no relay and no local discovery unless `sync.relays` or `sync.mdns` in `config.json` turns them on. A member can fetch the curator's pages from any other member that holds them, so the curator needn't be online.
- **Invite and join replace pairing.** `xenolith invite <space>... --level write` on the curating machine prints an invite and a code. `xenolith join <invite>` on the other machine reads the code from a prompt. An invite works once, for ten minutes, and five wrong codes retire it. `xenolith pair` is gone.
- **Shared mode with XenoNet.** With XenoNet 0.7.0 on the machine, Xenolith can sync through XenoNet's network instead of its own invites. Turn it on in XenoNet's **Network settings › Shared context**.

## What to know

- 1.x and 2.0 don't sync with each other. Move every machine that syncs in one sitting.
- Make each client's token again with `xenolith token create` once the 2.0 service runs. Apps that start Xenolith themselves, as Claude Code and Codex do, need no token.
- On Windows, shared mode isn't available yet. Join by invite instead.

## Install

Download the archive for your machine and `SHA256SUMS` from this release. Unpack the archive anywhere and run `xenolith install` in the unpacked folder. The installer copies the programs into Xenolith's own folders, so you can delete the download afterwards.

| Machine | Archive |
| --- | --- |
| Mac with Apple silicon | `xenolith-2.0.0-darwin-arm64.tar.gz` |
| Mac with an Intel processor | `xenolith-2.0.0-darwin-x64.tar.gz` |
| Linux x64 | `xenolith-2.0.0-linux-x64.tar.gz` |
| Windows x64 | `xenolith-2.0.0-win32-x64.zip` |

### macOS

```bash
cd ~/Downloads
curl -LO https://github.com/willctl/xenonet/releases/download/xenolith-v2.0.0/xenolith-2.0.0-darwin-arm64.tar.gz
curl -LO https://github.com/willctl/xenonet/releases/download/xenolith-v2.0.0/SHA256SUMS
shasum -a 256 -c SHA256SUMS --ignore-missing
tar -xzf xenolith-2.0.0-darwin-arm64.tar.gz
cd xenolith-2.0.0-darwin-arm64
./xenolith install
```

On an Intel Mac, use `darwin-x64` in the names. The programs are signed ad hoc and not notarized, so macOS refuses to run them when a browser downloaded the archive. Download with `curl` as above, or run `xattr -dr com.apple.quarantine xenolith-2.0.0-darwin-arm64` on the unpacked folder before installing. The programs go to `~/Library/Application Support/Xenolith`.

### Linux

```bash
curl -LO https://github.com/willctl/xenonet/releases/download/xenolith-v2.0.0/xenolith-2.0.0-linux-x64.tar.gz
curl -LO https://github.com/willctl/xenonet/releases/download/xenolith-v2.0.0/SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing
tar -xzf xenolith-2.0.0-linux-x64.tar.gz
cd xenolith-2.0.0-linux-x64
./xenolith install
```

It runs on glibc 2.39 or later, such as Ubuntu 24.04 or Debian 13. The tray needs GTK 3, WebKitGTK 4.1 and the Ayatana app indicator. On Debian or Ubuntu: `sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0 libayatana-appindicator3-1`. The programs go to `~/.local/share/xenolith`.

### Windows

Open a normal terminal (Win+R, `cmd`, Enter), not the terminal inside the Claude or ChatGPT desktop app. Then:

```bat
cd %USERPROFILE%\Downloads
certutil -hashfile xenolith-2.0.0-win32-x64.zip SHA256
tar -xf xenolith-2.0.0-win32-x64.zip
cd xenolith-2.0.0-win32-x64
xenolith.exe install
```

Compare the hash `certutil` prints with the zip's line in `SHA256SUMS`. Approve the administrator prompt: it registers the Xenolith service. The programs aren't signed, so Windows may say the publisher is unknown. They go to `%LOCALAPPDATA%\Xenolith`.

### After installing

Restart the Claude and ChatGPT desktop apps so they load the plugin and the server. If the curator isn't signed in yet, sign it in once: tray icon > **Curator** > **Sign in to ChatGPT for the curator...**. Until then, notes wait in the inbox.

## Upgrading from 1.x

1. Stop Xenolith and copy the shared context folder, the config folder and the state folder. Keep the 1.10.0 archive.
2. Run `xenolith install` from the unpacked 2.0.0 archive. Until the next step, 2.0 reads and writes the folder as 1.x did.
3. Run `xenolith upgrade` to see what it will do, then `xenolith upgrade --run`. It adds a marker to each space folder and founds each space's chain. It changes no page and deletes no 1.x file.
4. On machines that synced under 1.x, join them again by invite. The [README](https://github.com/willctl/xenonet/blob/main/xenolith/README.md#from-1x-to-20) has the order for several machines.

To go back: run `xenolith upgrade --undo` while 2.0 is still installed, stop Xenolith, restore the config and state folders from your copy, and install 1.10.0 again.
