# XenoNet 0.5.0

This version is being prepared as an installation candidate. It is not a
published release. Use the candidate's file hashes when requesting approval
on a managed computer.

Since 0.4.0:

- The map shows the other machines in your network. Select a remote session
  to inspect it from XenoNet's window.
- Machines can publish local HTTP services to their network. Requests and
  answers stay off the gateway's disk and have limits on size and time.
- Xenolith adds release packages, migration from Agent Wiki and shared
  context words. Its changes remain subject to its own installation steps.
- The doctor checks token drift, and Windows updates handle a binary that
  is still in use.
- The README video hides recording dates and times. The README also states
  the license boundary for documentation images and videos.

Desktop, Service, Tools and the Claude Code plugin are 0.5.0. The unchanged
macOS tray remains 0.4.1.

For a Windows installation with Hermes in WSL, follow
[Managed Windows installation](../guide/managed-windows.md). The candidate
does not add an enforced observation-only mode. Hermes's existing observer
reads activity and edit metadata, not full conversation text.

Build the candidate with the Release workflow on its branch. A manual run
uploads artifacts without publishing a release. Before tagging or
publishing, finish the GPU, packaged-app restart and target-host checks in
[Releasing XenoNet](../guide/releases.md).
