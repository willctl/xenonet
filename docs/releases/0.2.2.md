# XenoNet 0.2.2

- Route task and Review decisions preview an opt-in JevRouter request and show scores, policy exclusions and recorded outcomes. Suggestions do not start agents; task text is omitted from saved receipts.
- Launch sandbox adds reviewed, detached OpenShell jobs, optional project uploads and policy files, gateway checks, inspection and explicit deletion. Windows uses an installed WSL distribution. Runtime policy denials remain separate from model refusals.
- Review Pi runs reads Native Pi metadata on request and imports pi-harness JSON run exports, omitting prompts and tool content. Reading Pi sessions is off until enabled.
- The console driver and MCP integration browser can filter, sort, page and select records. Execution and source configuration remain in the owner's window.
- Adds unit, API and native UI coverage for the integration workflows and their failure paths.
- Token use keeps OpenRouter visible when its key is missing or rejected, with a setup action, and refreshes after credential changes.
