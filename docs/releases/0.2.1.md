# XenoNet 0.2.1

Successful searches, pagination and polling no longer trigger **may be stuck** just because the same tool runs several times. XenoNet compares complete call inputs and requires repeated completed failures for a retry-loop warning. Different calls need at least five consecutive failures spanning a minute before they produce a failure warning.

Warnings clear when a call succeeds, the turn ends, or a new turn starts. Waiting for an answer or approval does not count as stalled work. Codex tool replies refresh activity, so a session receiving results does not look silent.

Service and Tools are both 0.2.1.
