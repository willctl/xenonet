# XenoNet 0.6.3

You can answer a session's question from Needs you, on any machine. Desktop, Tools and the Service are 0.6.3.

## Changes

- **Go ahead, No and Answer… on a question.** A session that ends its turn asking something shows in Needs you, on its own machine and on every window host. On a window host the row now has **Go ahead**, **No** and **Answer…**. XenoNet sends the answer itself, as you at that console, to the session here or on another machine. The session reads "verified: you, at inix's console", and a session that ended is resumed to take it.
- **An agent can't answer for you.** The buttons are yours alone, like Allow: XenoNet's control channel doesn't press them outside the demo. A message from another session still can't approve anything, so a session asked by an agent to do something that needs your say-so waits for you here instead of for the agent.
- **A permission still answers in its own app,** and a run XenoNet started asks for a tool here with Allow and Deny, as before.

## Updating

1. Update Desktop. On Windows, open **Updates** and choose **Restart and update**. On a Mac, replace XenoNet in Applications with the copy from the new disk image, and open it.
2. Update the Tools, then the Service: in **Updates**, or with `xenonet update tools` and then `xenonet update service`.
3. Update every machine you answer from or ask on. A machine on 0.6.1 still ends a start with "ended (exit N)" and says it can't tell more.

`SHA256SUMS.txt` lists checksums for the downloads.
