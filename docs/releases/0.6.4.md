# XenoNet 0.6.4

You can tell an assistant "do this on the other machine" and have it done there, without going to that machine. Desktop, Tools and the Service are 0.6.4.

## Changes

- **A machine can take delegated work.** Set its **Start sessions** to **Delegated** once, from your own console: in the Network panel, or with `xenonet net set --on neo-rex --start delegate`. The buttons are yours alone, and putting another machine on delegation takes the founder or a second window host, as letting the network start sessions does. The machine keeps who set it and when, and the console shows both.
- **`delegate` hands it a task.** An assistant calls the `delegate` tool with a machine and a task. The answer comes at once, and the assistant is told how the session ended and woken for it. A machine that isn't on Delegated refuses and says how you set it.
- **The session is told it's your delegation.** Its first prompt names the machine that put it on delegation and the day, written by the machine from its own settings, so the asker can't claim it. Before, a session an agent started stopped to ask about anything that mattered.
- **What's covered runs without a question, the rest comes to you.** Reading, editing files under the session's folder, routine commands, and XenoNet's own update and doctor run at once. Deleting, secrets, the network, spending, files outside the folder and anything not listed show in Needs you on every window host, saying why they weren't covered. [Delegating work to another machine](../guide/delegation.md) lists both.
- **Clearer when a machine is too old.** A start that ends on a machine running an older XenoNet now says to update it there, and not to take it for done.

## Updating

1. Update Desktop. On Windows, open **Updates** and choose **Restart and update**. On a Mac, replace XenoNet in Applications with the copy from the new disk image, and open it.
2. Update the Tools, then the Service: in **Updates**, or with `xenonet update tools` and then `xenonet update service`.
3. Update the machine you delegate to before you set it to Delegated: a machine on 0.6.3 or older doesn't take that setting.

`SHA256SUMS.txt` lists checksums for the downloads.
