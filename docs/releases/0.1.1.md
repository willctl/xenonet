# XenoNet 0.1.1

XenoNet now says SI (super intelligence) where it said AI or agents. That covers the console's labels, the `xenonet` command's help and status, the doctor, and the instructions XenoNet gives the SI it connects. Command and tool names stay the same, so scripts and connected apps keep working.

## Downloads

- On Windows, [XenoNet Setup](https://github.com/willctl/xenonet/releases/download/v0.1.1/XenoNet-Setup-0.1.1.exe) installs Desktop, Service and Tools.
- On an Apple silicon Mac, download [XenoNet for Apple silicon](https://github.com/willctl/xenonet/releases/download/v0.1.1/XenoNet-0.1.1-arm64.dmg). On an Intel Mac, download [XenoNet for Intel](https://github.com/willctl/xenonet/releases/download/v0.1.1/XenoNet-0.1.1-x64.dmg).
- The Desktop-only downloads and the Service and Tools archives are for XenoNet's updater and for [installs without Desktop](https://github.com/willctl/xenonet/blob/main/docs/guide/components.md).

## Updating

On Windows, open **Updates** and choose **Restart and update** for Desktop. Then install the Service and Tools updates there, or run `xenonet update all`.

On a Mac, replace XenoNet in Applications with the copy from the new disk image, and run `xenonet update all`. Your settings stay in place.

Without Desktop, `xenonet update all` is the whole update. The service update waits while XenoNet's terminals run, so close them first.

`SHA256SUMS.txt` lists checksums for the downloads.
