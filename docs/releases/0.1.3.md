# XenoNet 0.1.3

XenoNet keeps SI for its name, "The network for SI." The console, the `xenonet` command, the doctor and the instructions connected apps read now use plain words: sessions, Claude Code and Codex, and each actor by name. The status row reads `Sessions`, the filter reads "Background sessions", and the doctor's button reads "Ask Codex or Claude Code…". Command and tool names stay the same, so scripts and connected apps keep working.

## Downloads

- On Windows, [XenoNet Setup](https://github.com/willctl/xenonet/releases/download/v0.1.3/XenoNet-Setup-0.1.3.exe) installs Desktop, Service and Tools.
- On an Apple silicon Mac, download [XenoNet for Apple silicon](https://github.com/willctl/xenonet/releases/download/v0.1.3/XenoNet-0.1.3-arm64.dmg). On an Intel Mac, download [XenoNet for Intel](https://github.com/willctl/xenonet/releases/download/v0.1.3/XenoNet-0.1.3-x64.dmg).
- The Desktop-only downloads and the Service and Tools archives are for XenoNet's updater and for [installs without Desktop](https://github.com/willctl/xenonet/blob/main/docs/guide/components.md).

## Updating

On Windows, open **Updates** and choose **Restart and update** for Desktop. Then install the Service and Tools updates there, or run `xenonet update all`.

On a Mac, replace XenoNet in Applications with the copy from the new disk image, and run `xenonet update all`. Your settings stay in place.

Without Desktop, `xenonet update all` is the whole update. The service update waits while XenoNet's terminals run, so close them first.

`SHA256SUMS.txt` lists checksums for the downloads.
