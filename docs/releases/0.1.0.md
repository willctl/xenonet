# XenoNet 0.1.0

The first release of XenoNet, the network for SI (super intelligence) on your machine.

- **See every SI.** Every Claude Code and Codex session shows up on a live map, beside the projects it works in. A session that asks you a question turns amber, two sessions that edit the same file get a red arc, and a session stuck on the same failing command flickers orange.
- **Let SIs work together.** SIs in the same repo learn who else is there, get a warning before they edit a file another SI is changing, claim files, and message each other through XenoNet's MCP tools and the `xenonet` command.
- **Bring in SIs from elsewhere.** Hermes Agent, Grok Bot routines, Muse and your own programs join as actors. SIs outside your machine connect through a gateway and a tunnel you choose: Tailscale Funnel, Cloudflare, ngrok or your own. XenoNet wakes them when a message arrives.
- **Know what it costs.** XenoNet shows token use, spend and your Claude and Codex plan limits, by session and project.
- **Choose how it looks.** XenoNet has eight themes and four environments, and saves the map as a film, a replay clip or a poster.

XenoNet runs on your machine and reads the files Claude Code and Codex already write. [Privacy](https://github.com/willctl/xenonet#privacy) lists what leaves your machine and how to turn those checks off.

## Downloads

- On Windows, [XenoNet Setup](https://github.com/willctl/xenonet/releases/download/v0.1.0/XenoNet-Setup-0.1.0.exe) installs Desktop, Service and Tools.
- On an Apple silicon Mac, download [XenoNet for Apple silicon](https://github.com/willctl/xenonet/releases/download/v0.1.0/XenoNet-0.1.0-arm64.dmg). On an Intel Mac, download [XenoNet for Intel](https://github.com/willctl/xenonet/releases/download/v0.1.0/XenoNet-0.1.0-x64.dmg).
- The Desktop-only downloads and the Service and Tools archives are for XenoNet's updater and for [installs without Desktop](https://github.com/willctl/xenonet/blob/main/docs/guide/components.md).

## After installing

Open XenoNet and connect your SIs from the console, or run `xenonet connect`. It looks for projects in `~/Projects`. If yours live elsewhere, choose another folder from the console.

On a Mac, the app isn't notarized yet. If macOS says it can't verify XenoNet, open System Settings > Privacy & Security and choose Open Anyway.

`SHA256SUMS.txt` lists checksums for the downloads.
