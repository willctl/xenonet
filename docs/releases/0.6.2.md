# XenoNet 0.6.2

A session you start, on this machine or another one, now tells you what it did, and wakes you when it's done. Desktop, Tools and the Service are 0.6.2.

## Changes

- **The end of a start says what happened.** Before, you heard that a run "ended (exit 0)", which also described a session that had stopped to ask "want me to go ahead?" and done nothing. Now XenoNet reads the session's own output and says one of: finished (with or without a report of its own), stopped to ask something (with the question), stopped for want of permission to a tool, failed (with why), or ended without a word. It quotes the session's last words.
- **You hear it when the turn ends,** not when the process exits. A session XenoNet starts waits a few minutes for a reply after its turn, so the end used to arrive up to five minutes late.
- **XenoNet reports back for the new session.** The session no longer has to be told to call `send`. Its last words reach whoever asked, whether or not it sent anything.
- **The session that asked is woken.** An idle session gets the end of its own start at once, as a resumed turn or a copy of it, even when the machine's wake setting is `consent`. The ask is the consent. The wake budgets, a pause and a plan near its limit still hold it back, and the note authorizes nothing.
- **The console shows the same words.** A start you asked for from the console toasts its end with the last words, and a session that stopped to ask, was denied a tool or failed shows as needing you.

## Updating

1. Update Desktop. On Windows, open **Updates** and choose **Restart and update**. On a Mac, replace XenoNet in Applications with the copy from the new disk image, and open it.
2. Update the Tools, then the Service: in **Updates**, or with `xenonet update tools` and then `xenonet update service`.
3. Update the machine that runs the session as well as the one that asked. A machine on an older XenoNet reports only that the run ended and its exit code, and the answer says it can't tell more.

`SHA256SUMS.txt` lists checksums for the downloads.
