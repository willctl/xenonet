# XenoNet 0.7.0

XenoNet's core is rewritten in Rust, and machines now connect to each other directly instead of through a gateway. This release doesn't read what 0.6 made, so each machine is set up again. Desktop, Tools and the Service are 0.7.0.

## Changes

- **One program.** The service, the `xenonet` command, the hooks and the MCP servers are one Rust binary, `xenonet`. It keeps everything in one store, `xenonet.sqlite`, and watches the apps' files instead of polling them.
- **Machines connect directly.** Machines in a network reach each other over encrypted QUIC connections that find a path through NAT. A relay helps when they can't reach each other directly, and carries only traffic it can't read. You choose the relays: none, [your own](../guide/own-relay.md), or n0's public ones. Finding machines on the LAN (mDNS) is a setting, off by default. The network gateway is gone.
- **Joining by invite.** **Add a machine** in the palette prints a `xenonet net join` line and a code. The code works once, for ten minutes. A machine can be in several networks.
- **Your identity.** Setting up asks you to make your identity: a key on each machine that asks you before it signs (Touch ID on a Mac, Windows Hello on Windows), plus a second device or a recovery phrase. What lets anyone do more, such as adding a machine, widening a setting or allowing an actor, asks you first.
- **Grants for every actor.** Every actor, bot and cloud assistant holds a grant that names what it may read and do. Widening one asks you.
- **Mailboxes.** A machine you name as a mailbox holds messages and work for a machine that's away, and passes them on when it's back.
- **Work for any machine.** An intent can name a machine, or let any machine in a delegation network take it. Delegation is a grant you sign once over a set of your machines.
- **More apps.** XenoNet speaks A2A both ways, works with any agent that speaks ACP, and supports MCP's 2026-07-28 version. On Windows, a machine's key can live in the TPM.
- **Shared context across machines.** With Xenolith 2.0, spaces can sync through your network: **Network settings › Shared context**.

## Updating

0.7.0 doesn't read 0.6's store, network, tokens or settings, so set each machine up again:

1. Update Desktop. On Windows, open **Updates** and choose **Restart and update**. On a Mac, replace XenoNet in Applications with the copy from the new disk image, and open it.
2. Update the Tools, then the Service: in **Updates**, or with `xenonet update tools` and then `xenonet update service`.
3. Follow the window's setup: make your identity, then start a network (`xenonet net create`) on one machine and invite the others ([A network across your machines](../guide/network.md)).
4. Connect your agents again (`xenonet connect`), and restart open sessions. In Codex, run `/hooks` once.
5. Pair actors again, and make new tokens for the actor gateway and the Hermes plugin.

`SHA256SUMS.txt` lists checksums for the downloads.
