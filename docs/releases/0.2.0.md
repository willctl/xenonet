# XenoNet 0.2.0

**Review provider refusals** in the command palette opens a browser for saved refusal records. Search the whole collection, filter by provider, outcome, model, category, saved context or date, and sort results. Select a record to read its provider signal and session metadata; open its saved request separately.

The panel distinguishes refusals, recovered requests, reroutes and possible refusals. Results are paged, so records beyond the previous 500-record API limit remain searchable. Browsing leaves context recording settings unchanged.

Service and Tools are both 0.2.0. The console driver and console MCP expose the browser through `refusals` actions.
